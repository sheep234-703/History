# 假如历史有朋友圈

电脑端课堂展示网站，包含首页三段宣传叙事、独立年份时间轴、独立朋友圈和图文发布编辑器。

## 内容

30个纪念日、47幅文档配图来自用户提供的《纪念日整合》。`public/data.js`保留原条目；历史细节与配图出处未补足的条目在界面提示待核。事件年份与史料出版年份分别呈现。

## 发布与存储

- 页面由Vinext根路由提供，交互代码在`public/app.js`，样式在`public/base.css`和`public/style.css`。
- `仅自己可见`的动态和未发布草稿仅存于当前浏览器。旧版localStorage内容只迁移到本地视图。
- `公共广场`通过`/api/moments`写入D1。接口不返回作者凭证。匿名访客使用HttpOnly浏览器凭证管理自己发布的内容。
- 支持公开动态、画报选图、点赞、评论、撤下和短时撤销。撤下为软删除。
- 公开信息流展示最近100条动态，每条最多展示100条评论，使用刷新按钮获取更新。
- 公开动态管理权限与浏览器凭证关联；清除网站数据后无法识别该浏览器原来发布的动态。

## 验证

`node --check public/app.js`、`npx tsc --noEmit`，以及Sites的构建入口。`tests/shared-api.mjs`用于可从执行环境直接访问服务时的多访客HTTP集成验证：`TEST_ORIGIN=<origin> node tests/shared-api.mjs`。

浏览器验证覆盖：三个页面导航、关联事件编辑器、画报选择和预览、公开发布、跨窗口读取和点赞评论、本地发布、旧版本地数据迁移、事件详情到发布页、撤下与撤销。

本地预览数据库和发布数据库独立；预览中的测试动态不写入线上。

## 自选配图

发表界面采用微信式单栏结构：想法、图片网格、关联事件与视角、可见范围、取消与发表。支持9张混合配图和只发图片。JPG、PNG、WebP自选图片在浏览器重绘压缩、移除相机元信息。原图上限15MB。

仅自己可见时，图片与动态存于当前浏览器；公开发表时才将自选图片上传到R2。D1新增`moment_uploads`记录图片所有者，公开发表只接受当前访客上传的图片及关联事件的画报。图片接口只提供被未撤下动态引用的图片，配图显示“用户配图”标签。

导航栏随页面滚走；滚动超过450px时显示返回顶部按钮。

新增浏览器验证：系统文件选择器添加图片、缩略图、与画报混搭、公开发表与图片实际加载、本地配图发表、非吸顶导航及返回顶部。

## 详细事件与地点资料

2026-11-01依据《纪念日事件（详细版）》《纪念日 地点》更新30个事件的时间、故事与地址；合并说明的纪念日映射回原有独立事件ID，未改动用户动态关联键。

`content/event-sources.json`保留每个事件对应的文档标题、原文段落和所列来源，供后续核对。公开详情页分开呈现事件内容、关联地点、画报信息，并在页尾列出各自来源及资料使用说明。所供文档没有原文链接的出处按名称列示，不推测网址。

发生地、指挥地、纪念活动地点及安葬地按语境区分；地址记载差异和文档明确标注的未核实内容予以提示。运行`node tests/content-check.mjs`检查30个条目的完整性、合并项对应关系及档案图片可用性。
